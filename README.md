# SpendWise

SpendWise is a simple, responsive expense tracker web app that helps you record, categorize, and visualize personal expenses. It's a small single-page application that runs in the browser — no backend required.

## Features

- Add, edit, and delete expenses
- View a running total and categorized breakdown
- Responsive layout for desktop and mobile
- Data persisted in the browser (localStorage)

## Demo

Open `index.html` in your browser or serve the repository with a static file server to try the app locally.

## Installation

1. Clone the repository:

   git clone https://github.com/Yash-Tummala/SpendWise-.git

2. Open `index.html` in your web browser, or use a local server such as Live Server in VS Code or:

   npx http-server .

## Usage

- Use the form on the page to add a new expense (amount, category, notes).
- Expenses are saved to your browser and will persist between sessions on the same device.
